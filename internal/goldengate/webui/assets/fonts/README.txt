The web UI's typefaces, from docs/brand/BRAND.md, embedded so the page loads
nothing from any other site. Latin subset, WOFF2, from the Fontsource packages
(federo 5.3.0, josefin-sans 5.3.0, ibm-plex-mono 5.2.5). Each is under the SIL
Open Font License 1.1; the licence files beside them apply.

  federo-400.woff2          Federo: display (wordmark, headings)
  josefin-sans-400/600      Josefin Sans: text, labels, buttons
  ibm-plex-mono-400/500     IBM Plex Mono: commands, paths, payloads, tags
